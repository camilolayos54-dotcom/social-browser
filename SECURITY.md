# Seguridad / Security

## Español

No publiques vulnerabilidades explotables ni credenciales en incidencias públicas. Contacta al responsable del repositorio mediante un canal privado o la función de aviso privado de GitHub si está habilitada. Incluye los pasos para reproducir el problema, el impacto y la versión afectada, sin incluir datos privados reales.

Las claves se almacenan cifradas solo si el almacén seguro del sistema está disponible; de lo contrario permanecen en memoria. Los perfiles, cookies, borradores y el descriptor temporal del agente son datos locales sensibles y no deben compartirse. El proveedor de IA recibe las instrucciones y el contenido que se le envíe. Un servidor compatible por HTTP recibe los datos sin cifrar. El acceso de agente permite leer contenido visible de los perfiles autorizados: conéctalo solo a clientes de confianza. Esta revisión no sustituye una auditoría independiente.

## English

Do not post exploitable vulnerabilities or credentials in public issues. Contact the repository owner through a private channel or GitHub's private vulnerability reporting feature if enabled. Include reproduction steps, impact, and the affected version without real private data.

Keys are encrypted at rest only when the system secure store is available; otherwise they remain in memory. Profiles, cookies, drafts, and the temporary agent descriptor are sensitive local data and must not be shared. The AI provider receives the prompts and content sent to it. A compatible server over HTTP receives data without encryption. Agent access can read visible content from authorized profiles: connect only trusted clients. This review is not a substitute for an independent audit.
